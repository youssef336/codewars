## About

A practice log of [Codewars](https://www.codewars.com/) challenges solved in C++. Each file contains the kata description as a comment followed by my solution — some include a second, more concise approach after a first straightforward one. Everything here is currently **8 kyu** (beginner level), focused on the building blocks: loops, conditionals, string manipulation, `std::vector` and integer arithmetic.

## 📚 Concepts practised

- 🔤 String manipulation — reversing, slicing, filtering characters, case swapping, repetition
- 🔢 Arithmetic & modulo — even/odd, divisibility, centuries, quarters, time conversion
- 📦 `std::vector` traversal — min/max, product, sign inversion
- 🔀 Conditionals and the ternary operator
- 🔄 Type conversion — `std::stoi`, bool → string

## 🚀 Using the solutions

Each file holds only the kata function (no `main`), exactly as submitted on Codewars. To try one locally, add a small `main` that calls it and compile:

```bash
g++ -std=c++17 "codewars/8kyu/Even or Odd.cpp" my_main.cpp -o kata && ./kata
```
